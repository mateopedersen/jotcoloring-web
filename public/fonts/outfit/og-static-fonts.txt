Outfit social-cover build fonts

Derived from both bundled Outfit Latin and Latin Extended variable subsets at weights 550, 750 and 800 with fontTools varLib.instancer and merge. Both subsets are required for names such as Luka Dončić, Nikola Vučević and Alperen Şengün. The merged instances preserve the existing ASCII outlines and advance widths. These static instances are used by the local PNG renderer so the actual site typography remains consistent; browser pages continue using the original variable WOFF2.
