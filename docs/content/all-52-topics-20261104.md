# JotColoring 52-package release

The authorized release contains exactly 52 ZIP archives and 5,200 drawings. The complete archive checksums are pinned in `src/server/reviewed-release-scope.ts`, and each supplied ZIP has a checksum-verified private copy. This routing record is not editorial approval or a production seal.

## Exact topic routes

Every package uses its own `/coloring-pages/<topic>/` page. If that exact topic page already has matching published drawings, append the new drawings there without replacing existing IDs or artwork. If it does not, create the dedicated topic page. Then include its accurate parent category and collection in the topic lineage. A broad page such as Aircraft, Pets, Cars, or Weather is a parent destination only; it never replaces the dedicated Jet, Rabbit, Race Car, Rainbow, or Rain page. Character pages such as Amy Rose, Rarity, and Rainbow Dash keep their character route and their franchise route in the parent lineage.

The working taxonomy defines every exact topic and its complete parent lineage. Jet remains its own subject under Aircraft, Jungle under Jungle Animals, and each other package keeps its dedicated route. Existing empty category definitions are not evidence of published drawings. The production preflight found no existing records with the 52 new content ID prefixes, so this release creates 5,200 new records without replacing previous artwork.
